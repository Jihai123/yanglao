# V2 政策可信度与地区参数治理

日期：2026-08-28

## 目标

退休规划助手不能只“算出一个数字”，还要让用户知道：

- 哪些结论来自国家现行政策；
- 哪些参数来自参保地官方公开数据；
- 数据适用哪一年、什么时候发布；
- 哪些数字是长期预测假设，而不是待遇承诺；
- 用户如何去官方渠道交叉验证。

## 三层可信度

### 1. 国家政策规则

直接进入规则引擎，要求来源为国家权威部门，且页面可打开原文。

当前核心来源：

- 全国人大常委会 / 国务院：渐进式延迟法定退休年龄决定；
- 人力资源社会保障部、中共中央组织部、财政部：《实施弹性退休制度暂行办法》。

国家规则用于：

- 渐进式法定退休年龄；
- 最早 / 最晚弹性退休范围；
- 2030—2039最低缴费年限变化；
- 弹性提前、弹性延迟的最低缴费年限引用年份。

### 2. 地区参数

地区数值必须同时保存：

- `value`；
- `year`；
- `published`；
- `issuer`；
- `url`。

缺少官方来源或无法确认是否为当前最新值时，不自动带入。

当前首批已核验：

- 北京：2025养老保险待遇计算基数；2026社保缴费基数上下限；
- 上海：2026社保缴费基数上下限；2026最新企业基本养老金计发办法；
- 江苏：企业职工基本养老保险实施办法。

全国省级地区均可选择；未收录最新官方参数的地区进入 `manual` 模式，不借用其他地区数值。

## 3. 长期预测假设

以下内容不得显示为“政策精确”：

- 未来计发基数增长率；
- 未来工资 / 缴费基数增长率；
- 个人账户未来记账收益；
- 长期通胀；
- 未知个人账户余额的估算。

页面必须显示为规划预测，并允许用户查看假设。

## 页面呈现

### 首页

显示：

- `官方来源可核验`；
- `政策与数据已核验至 YYYY-MM-DD`；
- 最近一条与养老 / 退休相关的人社部官方动态；
- 可展开查看国家政策原文。

最新动态只作为信息展示，除非明确进入计算模型，否则标注“不直接改变本次金额公式”。

### 测算过程

在金额参数步骤增加“参保 / 退休地区”：

- 全国省级地区可选；
- 已核验地区展示参数年份和官方来源；
- 当前缴费基数超出已核验官方上下限时提示检查年份；
- 有可靠官方待遇计算基数时，精确输入模式允许用户一键带入，但不强制覆盖用户输入。

### 结果页

增加“政策与数据依据”：

- 国家规则：政策来源；
- 地区参数：地区、年份、发布机构；
- 金额：规划预测标签；
- 最后核验日期；
- 人社部官方养老待遇测算服务交叉验证入口。

## 更新规则

1. 不在浏览器运行时抓取政府网站，避免 CORS、网站结构变化和不可审计数据直接影响计算。
2. 官方信息先进入受版本控制的 `js/sources.js` 注册表，经核验和测试后发布。
3. 任何地区自动数值必须附官方 URL 与适用年份。
4. 新政策如果改变规则，先更新规则测试，再更新页面说明。
5. 纯新闻 / 工作动态不得直接改变金额计算。
6. 旧数据可以保留为历史参考，但不得标成“当前最新”。
